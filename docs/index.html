QSuite

QSuite is a lightweight testing framework for QuantumC. It provides simple assertions, exception testing, colored output, and automatic timing.

Getting Started

#include<qsuite, qsuite@/lib/core.qc> // Assumes that you have the package installed from the registry on the package manager
qsuite::Suite::Suite suite(qsuite::Suite::Settings{ColorMode.Always, max_ms = 100});
suite(fn(qsuite::Test::Test t) {
    t.expect(1 + 1, "addition").toBe(2);
}, "Math Tests");
Produces output similar to:

        PASS

    1 passed

lib/core.qc

Creating a Test Suite

qsuite::Suite::Suite suite({
    .color_mode = ColorMode.Always,
    .max_ms = 250
});
Setting Description
color_mode Enable or disable ANSI colors.
max_ms Warn if the test run exceeds this time. (Double, Milliseconds)

Assertions

Equality

t.expect(answer, "returns 42")
    .toBe(42);

Not Equal

t.expect(value, "not zero")
    .toNotBe(0);

Greater Than

t.expect(score, "positive score")
    .toBeGreaterThan(0);

Less Than

t.expect(speed, "below limit")
    .toBeLessThan(100);

At Least

t.expect(count, "minimum count")
    .toBeAtLeast(10);

At Most

t.expect(level, "maximum level")
    .toBeAtMost(5);

Approximate Equality

t.expect(pi)
    .toBeAround(3.14159);
Or specify your own tolerance: 
t.expect(result)
    .toBeAround(10.0, 0.5);

Exception Testing

Expect an exception: 
t.throws(fn() {
    dangerousFunction();
}, "throws on invalid input");
Expect no exception: 
t.doesntThrow(fn() {
    safeFunction();
}, "runs successfully");

Manual Logging

Sometimes an assertion isn't enough. 
if (condition) {
    t.logPass("configuration loaded");
} else {
    t.logFail("configuration missing");
}

Example

...
suite(fn(qsuite::Test::Test t) {
    t.expect(5 * 5, "multiplication")
        .toBe(25);
    t.expect(10)
        .toBeGreaterThan(5);
    t.expect(3.1415)
        .toBeAround(3.14, 0.01);
    t.throws(fn() {
        throw "error";
    }, "throws correctly");

}, "Example Tests");

Available Assertions

Method Description
toBe() Equality
toNotBe() Inequality
toBeGreaterThan() Greater than
toBeLessThan() Less than
toBeAtLeast() Greater than or equal
toBeAtMost() Less than or equal
toBeAround() Approximate equality
throws() Function should throw
doesntThrow() Function should not throw
logPass() Record a passing check
logFail() Record a failing check

lib/runner.qc

Runner really only has one thing in it. It runs all the .test.qc files in your directory. So a example runner file would be: 

namespace Exported {
    #include<qsuite, qsuite@/lib/runner.qc>
}
int main() {
    return qsuite::Runner::runTests();
}
